# Dave Video Workflow

把使用者自己的口播素材制作成可检查、可继续修改的项目。按当前阶段读取相应参考文档，不预先加载全部文件。

## 先确认项目与执行能力

查看用户指定的本期目录和当前编辑器项目，确定素材版本、已确认结果、当前阶段及目标画幅。只在影响当前工作的必要信息缺失时询问，不要求用户重复提供已有信息。新项目的编号和目录规则见 [文件与交付](references/files-and-handoff.md)。

实际剪辑前确认视频工具已经连接、当前项目正确、源素材已经由用户导入。优先使用当前环境提供的视频工具及其配套操作指引，不臆造 API、工具名、资产 ID 或绝对路径。本 Skill 只规定制作方法，不替代视频工具。

没有相应能力时，完成可执行的部分并标注边界：只有文字稿时可给清理建议，但不能声称完成音视频剪辑；没有真实时间信息时不能编造字幕时间；没有图像工具时交付封面方案或提示词，不能冒充图片。

## 确认与权限

- 默认完成一个阶段后先保存、展示结果，再等待用户确认；MG 分为方案确认和成品确认。
- 用户已明确授权连续完成哪些阶段时，在该范围内继续，不反复询问。同意一个结果不自动等于授权所有后续阶段。
- 默认由用户导入素材、导出视频和发布。用户明确委托其中某项操作时，按当前工具的权限和要求执行；不能把制作授权解释成对外发布授权。
- 修改已确认剪辑后，检查依赖它的 MG、字幕和文案，说明哪些结果需要重新确认；不默默沿用过时结果。
- 只处理本期内容。没有用户提供的授权，不调用其他项目素材、共享样片、旧账号信息或真实案例。

## 制作顺序

1. **口播剪辑**：读取 [剪辑规则](references/editing.md)。处理重说与瑕疵，保留原意、自然停顿和必要上下文。保存记录，展示可复听的结果。
2. **可选 MG**：仅在用户要求时读取 [MG 指引](references/motion-graphics.md)。先给位置、要解释的内容与时长建议，按确认后的方案制作和预览。没有现成模板也可以按可用工具制作；不依赖本仓库外的私人模板。
3. **字幕**：读取 [字幕规则](references/captions.md)。以最终确认的时间线或对应视频为基准，先校对与语义断句，再对齐口播时间并检查画面。
4. **文案**：读取 [文案与封面](references/copy-and-covers.md) 的文案部分。基于最终字幕或用户指定的最终稿写标题、正文、标签，不引用已删内容。
5. **封面**：读取同一参考文档的封面部分。使用确认后的标题、画幅和风格，保存并展示图片。不同尺寸要重新排版。
6. **归档交付**：读取 [文件与交付](references/files-and-handoff.md)。核对实际文件、版本和命名，交付链接和当前完成状态。

用户只要求某阶段时，只执行该阶段；例如已有最终字幕且只需文案，不要求重新剪辑或生成字幕。已确认阶段不重复制作。

## 完成判断

说明实际完成的内容、可检查的文件或编辑器预览、已做的检查、尚待确认或用户操作的事项。不能把“已写方案”“已加入时间线”“已导出文件”“已发布”混为一谈。交付前播放或渲染核验实际产物；无法验证的部分如实标注，不用“全部通过”代替证据。
